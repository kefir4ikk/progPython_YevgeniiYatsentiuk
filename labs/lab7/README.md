## Що реалізовано

**`functional_pipeline.py`**

- `calculate_reliability_metrics(*intervals_h, **options)` - MTBF, MTTR, коефіцієнт готовності `A = MTBF / (MTBF + MTTR)`, інтенсивність відмов `λ = 1 / MTBF` та ймовірність безвідмовної роботи `R(t) = exp(-λ t)`; опції `mttr_hours`, `mission_time_h`, `strict` зі значеннями за замовчуванням; валідація інтервалів, перевірка імен опцій (`TypeError` для опечаток);
- `make_call_counter` - замикання з `nonlocal` (правило LEGB);
- `sorted(..., key=lambda r: (-r["cpu_usage"], r["ram_free_gb"]))` - багатокритеріальне сортування;
- `filter`, `map` та `min` з lambda-виразами.

**`recursive_algorithms.py`**

- `merge_sort_recursive` - рекурсивний поділ навпіл, базовий випадок `len <= 1`, злиття через `merge`;
- `RecursionDepthTracker` - облік глибини стека, кількості викликів і порівнянь, генерація `RecursionError` при перевищенні безпечного ліміту;
- `merge_sort_iterative` - висхідний ітеративний аналог без рекурсії;
- порівняння часу рекурсивного, ітеративного сортування та `sorted()` для `N` від 1 000 до 100 000;
- звірка теоретичної глибини `D(n) = ceil(log2 n) + 1` зі зафіксованою.
