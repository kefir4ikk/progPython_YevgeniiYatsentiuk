## Що реалізовано

**`network_inventory.py`**

- реєстр із 10 користувачів, ключ - `Username`, значення - вкладений словник; ролі зберігаються як `set`;
- `add_or_update_user` - додавання та оновлення через `update()`;
- `remove_user` - вилучення через `pop(key, None)` без `KeyError`;
- `get_user_email` - безпечний доступ через `get()`;
- `grant_role` / `revoke_role` - `setdefault()` та `discard()`;
- `build_inverted_role_index` - Dict Comprehension `role -> [users]`.

**`security_audit.py`**

- `ROLE_TEMPLATES` - шаблони ролей за відділами у вигляді `frozenset`;
- `audit_user_roles` - надлишкові права `A \ B`, відсутні права `B \ A`, перетин `A ∩ B` та індекс Жаккара `J(A, B)`;
- для неактивних облікових записів еталон - порожня множина: збережені права дають статус `КРИТИЧНО`;
- `Counter` потоку входів: топ-3 через `most_common(3)`, входи за відділами;
- множинні перевірки журналу проти реєстру: невідомі облікові записи, входи неактивних записів, активні записи без входів.
